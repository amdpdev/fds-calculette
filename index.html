Taux de change

Les taux ne se mettent pas à jour tout seuls : saisissez ceux du jour, ils sont retenus sur cet appareil. Les taux de départ (1,17 $ et 0,87 £) ne sont que des valeurs d'amorçage.

✎ Vous renseignez

Table coefficient ↔ marge

Quel coefficient pour obtenir telle marge ? Touchez une ligne pour la reporter dans le calcul.

Bien lire les résultats

Coefficient = prix de vente ÷ prix d'achat.
Marge = (prix de vente − prix d'achat) ÷ prix de vente.
Un coefficient de 1,50 donne une marge de 33,3 %, pas de 50 %.
Tous les prix sont HT.

  • Cadre jaune : ce que vous renseignez. Cadre vert : le résultat, rien à saisir.
  • La ligne que vous tapez pilote les autres ; une ligne « calculé » reprend la main dès que vous y tapez.
  • « ± » donne une marge négative (vente sous le prix d'achat).
  • Renseignez un tarif pour faire apparaître la ligne « Remise sur tarif » : la remise à appliquer au tarif pour obtenir ce prix de vente (un « + » indique une majoration).

Installer sur l'écran d'accueil

Pour l'ouvrir comme une application, plein écran, avec son icône.

iPhone (Safari) : touchez Partager ⬆︎, puis Sur l'écran d'accueil. Vous pouvez modifier le nom proposé avant de valider (« FDS Calc », par exemple, tient en entier sous l'icône).

Android (Chrome) : menu ⋮, puis Installer l'application (ou Ajouter à l'écran d'accueil).

Sans réseau, et sans rien envoyer

Après la première ouverture, FDS Calculette fonctionne sans réseau. Tous les calculs se font sur l'appareil : aucun prix, aucune saisie n'est envoyé ni enregistré ailleurs. Seuls les deux taux de change et le mode jour / nuit sont retenus sur l'appareil.
